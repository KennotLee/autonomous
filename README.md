# Runway Capacity & Delay Risk Forecasting (Autonomous SG 2026, Airbus Track, Challenge #5)

Predict airport runway capacity reductions (hourly arrivals, an AAR proxy) and flight-level severe delay risk (>45 min) 3–12 h before severe weather.

## Layout

```
data/raw/        provided dataset (committed)
data/external/   public downloads (regenerated by scripts/download_public_data.py, not committed)
data/processed/  derived tables (not committed)
scripts/         download / build / train entry points
src/             library code (features, targets, models)
tests/           unit tests (incl. time-leakage checks)
dashboard/       ATC decision-support dashboard
```

Work in progress.
